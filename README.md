Dashboard Financeiro - Excel

SOBRE O PROJETO

Este projeto é um dashboard financeiro interativo desenvolvido no Microsoft Excel
como parte dos meus estudos em análise de dados.
O objetivo é visualizar e acompanhar receitas, despesas e dinâmica.

FERRAMENTAS UTILIZADAS

-Microsoft Excel

-Tabela e Tabela Dinâmicas

-Gráficos

-Segmentação de Dados (filtro por mês)

-Indicadores financeiros(KPIs)

FUNCIONALIDADES

-Visualização de entradas e saídas por mês

-Anáçise de custos por categoria

-Comparação de entradas e saídas por forma de pagamento

-cartões com indicadores de entrada, saída e saldo mensal

-filtro interativo por mês

OBJETIVOS

Poder praticar minhas habilidades em Excel, organização de dados e criação de dashboards para análise e visualização de informações 

OBSERVAÇÃO

Projeto desenvolvido durante meus estudos, com base em um vídeo do youtube com dados disponibilizados pelo criador do conteúdo
